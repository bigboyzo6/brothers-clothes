# 👕 BrothersClothes - Retro E-Commerce Store

Web toko online pakaian bertema vintage/retro 80-an full-stack yang dibuat menggunakan HTML, CSS, JavaScript, Node.js, Express, dan MySQL.

---

 💻 Cara Menjalankan Project

### Prasyarat System:
* **Node.js** (Versi 14 ke atas)
* **Web Server & Database Environment** (Laragon / XAMPP — *Disarankan Laragon*)
* **Code Editor** (VS Code) + Ekstensi *Live Server*

---

### Langkah-langkah:

**1. Clone Repository**
```bash
git clone [https://github.com/bigboyzo6/brothers-clothes.git](https://github.com/bigboyzo6/brothers-clothes.git)
cd brothers-clothes

**2. Nyalakan Database (MySQL)**

Buka Laragon atau XAMPP.

Klik tombol Start untuk menyalakan Apache dan MySQL.

Buka phpMyAdmin di browser (http://localhost/phpmyadmin).

Buat database baru dengan nama: brothers_clothes.

3. Jalankan Backend (Node.js)
