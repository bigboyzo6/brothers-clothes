# 👕 BrothersClothes - Retro E-Commerce Store

Web toko online pakaian bertema retro 80an full-stack (HTML, CSS, JS, Node.js, Express, dan MySQL).

---

## 💻 Cara Menjalankan Project

Pastikan kamu sudah menginstal tools berikut di komputer kamu:
- [Node.js](https://nodejs.org/) (versi 14 ke atas)
- Web Server & MySQL Environment ([Laragon](https://laragon.org/) / [XAMPP](https://www.apachefriends.org/))
- Editor Kode (disarankan [VS Code](https://code.visualstudio.com/)) dengan ekstensi **Live Server**

### 1. Clone Repository
Buka Terminal / Command Prompt, lalu jalankan:
git clone https://github.com/bigboyzo6/brothers-clothes.git
cd brothers-clothes

### 2. Nyalakan Database (MySQL)
1. Buka Laragon atau XAMPP. (Disarankan memakai Laragon)
2. Klik tombol Start untuk menyalakan Apache dan MySQL.
3. Buka phpMyAdmin di browser (`http://localhost/phpmyadmin`).
4. Buat database baru bernama `brothers_clothes`.

### 3. Jalankan Backend (Node.js)
1. Buka Terminal di VS Code, lalu masuk ke folder backend:
   cd backend
2. Instal pustaka yang dibutuhkan:
   npm install
3. Jalankan server:
   node server.js

### 4. Jalankan Frontend (Tampilan Web)
1. Buka folder `FRONTEND` di VS Code.
2. Klik kanan pada file `index.html` -> pilih **Open with Live Server**.
