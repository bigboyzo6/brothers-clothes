👕 BrothersClothes - Retro E-Commerce Store
Web toko online pakaian bertema retro 80-an full-stack (HTML, CSS, JS, Node.js, Express, dan MySQL).

💻 Cara Menjalankan Project
Prasyarat System:
Node.js (versi 14 ke atas)

Web Server & MySQL Environment (Laragon / XAMPP)

Editor Kode (VS Code) dengan ekstensi Live Server

1. Clone Repository
Buka Terminal / Command Prompt, lalu jalankan:

Bash
git clone https://github.com/bigboyzo6/brothers-clothes.git
cd brothers-clothes

2. Nyalakan Database (MySQL)
- Buka Laragon atau XAMPP (Disarankan memakai Laragon).
- Klik tombol Start untuk menyalakan Apache dan MySQL.
- Buka phpMyAdmin di browser: http://localhost/phpmyadmin
- Buat database baru bernama brothers_clothes.

3. Jalankan Backend (Node.js)
- Buka Terminal di VS Code, lalu masuk ke folder backend:
cd backend
- Instal pustaka yang dibutuhkan:
npm install
- Jalankan server:
node server.js

4. Jalankan Frontend (Tampilan Web)
- Buka file index.html (di root folder) pada VS Code.
- Klik kanan pada file index.html -> pilih Open with Live Server.
